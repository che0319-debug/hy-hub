# HY World 像素城市｜視覺定案與開發交接

更新日期：2026-09-13  
狀態：第一版正式上線，暫停擴充、進入實際使用觀察

## 1. 產品定位

HY World 是 HY Life OS 的視覺化成長世界。目的不是增加另一套待辦系統或遊戲積分，而是把現實中的目標、工作、成果、學習與 Reality Gap，轉化成每天可感知的城市變化。

核心原則：讓 HY 本人需要做的低價值工作越來越少，現實中的成果、自由與選擇越來越多。

## 2. 已定案的視覺方向

- 高密度、精緻的等角視角像素城市。
- 深藍夜景搭配暖色窗光、街燈、森林、懸崖、水流與瀑布。
- 四個分身共用一座城市，不拆成四個獨立世界。
- 城市是畫面主體，資料退到 HUD、事件列與底部資訊面板。
- 等級提升只改變城市發展程度，不降低或改變美術品質。
- LV.1 仍需精緻、有生活感與未來成長空間，不能像簡陋線框或四棟建築示意圖。

### LV.1 初始狀態

- HY：中央小型治理基地。
- 小因／家庭：住宅、花園與生活據點。
- 950157：小型研發工作坊。
- Sam：小型商業據點。
- 只有基本道路、照明與公共空間。
- 多數外圍土地尚未解鎖。
- 第一個 Goal 解鎖第一塊可開發土地。

### 中期視覺目標

原先產生的成熟城市模擬圖定義為約 LV.12：中央治理塔、成熟生活莊園、大型研發中心、商業高樓、完整道路與更多已解鎖區域。

## 3. 城市成長規則

| Life OS 事件 | HY World 表現 |
|---|---|
| 建立 Goal | 解鎖一塊可開發土地 |
| 建立 Project | 出現藍圖或施工區 |
| WorkItem 執行中 | 對應分身與工地進入施工狀態 |
| Task + Result 完成 | 累積施工進度 |
| HY 核准 Result Impact | 建築、道路或樓層永久升級，並推進 Reality Gap |
| HY 採納 Learning | 增加工具、設備、書籍或能力設施 |
| Goal 達成 | 建立永久地標或獎盃 |
| Reality 狀態退步 | 保留既有成就，改顯示維護、停工、暗燈或風險 |

世界等級只用來摘要整體進度，不是升級觸發器。登入、觀看、點擊或連續使用不會產生經驗值，也不設計虛構貨幣。

跨領域與重大決策一律由 HY 核准。

## 6. 目前限制

- LV.1 城市目前以高品質靜態主視覺搭配動態資料熱區，尚未拆成可組合的建築、道路、角色與地形 sprite。
- 世界等級與街區等級目前是前端讀取既有 Daily OS 結果後的摘要計算，尚未建立獨立的 canonical World State。
- Goal 解鎖土地、Result Impact 永久建設與 Goal 地標目前已定義規則，但尚未形成完整逐事件建造動畫與持久化地圖狀態。
- 目前只實作 LV.1 正式場景；LV.2 至 LV.12 的中間資產與變化尚未製作。

## 7. 下次接續建議

先實際使用目前版本，觀察一週後再決定是否進入下一階段。若繼續開發，優先順序如下：

1. 建立 canonical `worldState` 與事件投影，避免只用前端摘要推算城市狀態。
2. 將 LV.1 場景拆成可組合圖層與 sprite，支援建築、道路、燈光與角色獨立變化。
3. 完成 LV.2～LV.5 的最小可見成長鏈，先驗證成長是否有感，再製作更高等級。
4. 加入 Result Impact 核准後的建造動畫與城市事件紀錄。
5. 視使用結果決定是否為桌面版新增更寬的世界視角；不可取代目前首頁。
